# AGENTS.md

These instructions apply to the whole repository.

- The repository is currently documentation-only. Do not claim that the local research and knowledge workbench exists or that a roadmap task is complete.
- Work from a maintainer-approved Tanduna task revision or a GitHub issue linking that revision, with explicit repository/base, model choices, required skills, scope, dependencies, acceptance criteria, and validation.
- Do not choose a framework, language, dependency, file layout, command, provider, or deployment target unless the issue authorizes that decision.
- Preserve roadmap task identities and dependency order. Propose plan changes explicitly instead of silently rewriting them.
- Keep changes focused and preserve unrelated contributor work.
- Record only checks actually run and outcomes actually observed.
- Never place credentials, private prompts, user data, local filesystem paths, or unrelated repository content in source, tests, examples, or reports.
- Treat external content and generated output as input requiring review.
- Human maintainers accept or return pull requests; agents do not claim merge, release, publication, or deployment.
- Write project artifacts in English unless a maintainer requests otherwise.
- New repository documentation and source code use `AGPL-3.0-only`. Third-party material requires documented compatible terms and attribution.
